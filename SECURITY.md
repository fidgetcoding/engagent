# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest (`main`) | Yes |

## Reporting a Vulnerability

If you find a security problem in Engagent, please report it privately:

1. **Don't open a public GitHub issue.**
2. Use GitHub's private reporting: the repo's **Security** tab → **Report a vulnerability**, or go straight to <https://github.com/fidgetcoding/engagent/security/advisories/new>. Only the maintainer sees the report.
3. Include what you found, how to reproduce it, and what it could affect.
4. You'll hear back within 48 hours.

## What's worth reporting

Anything that lets someone off your allowlist talk to your bot, open the web workspace without the password, or run up your Apify or Anthropic bill.
